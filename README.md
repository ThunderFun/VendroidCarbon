# VendroidCarbon

VendroidCarbon is an unofficial Android client for Discord. It runs Discord's web app in a WebView and applies Vencord or Equicord at runtime.

## Building

Requires JDK 21 and the Android SDK.

```sh
./gradlew :app:assembleDebug
```
